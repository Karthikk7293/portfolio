**Current portfolio:** https://portfolio-nextjs-zeta-eight.vercel.app/

This repository preserves an earlier version or design exercise. Current experience, case studies, and resumes are on the portfolio linked above.

## Run locally

Install Node.js and the package manager used below. Run each command block from the repository root; separate frontend/backend processes use separate terminals.

Root application:

```sh
pnpm install
pnpm run dev
```

Other package scripts: `pnpm run build`, `pnpm run lint`.
